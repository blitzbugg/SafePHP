# Security Policy

This project is a security tool in early development.

## Reporting a vulnerability

Do not publish secrets, exploit payloads against third-party systems, or sensitive server reports in public issues. Open a private security advisory through the repository's GitHub Security tab once private reporting is enabled. Until then, contact maintainers privately through a verified repository channel.

## Scope

Security reports about this extension, its dependency handling, local file access, or misleading detection behavior are in scope. Reports should include a minimal reproduction and impact assessment.

## Limitations

This tool is not a replacement for patch management, a full static analyzer, incident response, or vendor advisories.
